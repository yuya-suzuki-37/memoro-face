# 03 FaceLandmarker（478点）測定指標一覧＋採点の考え方

MediaPipe Face Landmarker の478点（468メッシュ＋虹彩10）から算出。座標は画像内相対値。**すべて正規化して無次元化**する。信頼度は07の再評価反映（初版より辛め）。

## 🔴 前処理（必須）
1. **ロール正規化**：両目中心を水平化してから角度・縦位置系を算出。
2. **姿勢・表情ゲート**：ヨー/ピッチが大きい（許容±5°目安）、笑み・開口・眉上げ・薄目は弾く／確信度を下げ再撮影を促す。
3. **分母の選択**：顔高は `|y10-y152|` より **鼻根168基準**を優先（y10=生え際相当で髪・姿勢で動く）。
4. **W（顔幅）の頑健化**：`dist(234,454)` は頬の軟部点で体重・むくみ・残存ヨーで動く。眼窩間距離・縦基準と併用してロバスト化（単一故障点にしない）。
5. **ノーメイク推奨**：描き眉・アイメイク・オーバーリップ・シェーディングは形状を人為的に変える。

## 採点の考え方（2軸スコア → 8タイプ）※07で下方修正済
1. **各指標を robust z 正規化**（母集団の中央値・MAD。固定・バージョン管理された基準母集団）。min-max混用はしない。
2. **おもざし軸 `S_age`**：下顔面比＝大重み、アイレベル・顔アスペクト＝中、目相対サイズ・鼻長＝小、額比・目間＝極小。
3. **かたち軸 `S_shape`**：目の丸み・目尻角度・顎幅/頬骨幅比を主に弱く合成。眉/頬/鼻先はスコア除外（フラグのみ）。共通誤差源の輪郭系は低重みまたは表示のみ。
4. **3帯化 → 8マス割付**（01/02の配置）。中央寄りは最近傍タイプ＋ミックス。
5. **確信度**：`+`＝両軸\|S\|大・写真品質良／`−`＝\|S\|小・低信頼指標依存・品質NG・非対角セル。総合上限は控えめキャップ。**極値らしさ≠精度**なので、可能なら複数枚のtest-retest分散/信頼区間で校正。
6. **透明性（UI）**：数値は出さず「おもざしは○○寄り・かたちは○○寄り」の**傾向表現**で提示。技術語（168基準・アンサンブル等）は内部に留める。

> 実装は必ず [[07-critique-and-revisions]] の重み・除外・確信度キャップに従う。
