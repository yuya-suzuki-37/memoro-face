# 08 較正ノルム（しきい値の根拠・出典付き）

各指標の「中心（平均的な顔＝2軸マップの原点）」と「帯の境界」を、**公開されている顔計測学のノルム**に基づいて設定する。数値は `calib.js` に集約（単一の情報源）。
🔴 前提：これらは母集団平均のノルムであり、Farkas自身が「新古典canonに合致する個人は少数」と示している。よって**絶対的正解ではなく、相対マップの原点**として使う。帯は広めに、確信度は控えめにキャップ（07）。

🔴🔴 **中心値の2系統（実装で判明・重要）**：
- **(A) ランドマーク非依存＝出典そのものを中心に採用（軸の背骨）**：
  - `下顔面比`(中心0.50)…縦の三分割の比なので計測点が変わっても等分＝0.5が成り立つ。
  - `目尻角度`(中心+5°)…度数で直接測れる（Farkas）。
  - `目の丸み`(中心0.32)…同一の目の高さ/幅比なので機器非依存。
  - → これらは学術ノルムをそのまま中心に使え、**軸の主指標**にする。
- **(B) 幅正規化＝機器依存（頬骨幅 234-454 が臨床zygionより広い）**：
  - `顔の縦横比`『臨床の顔面指数0.85-0.90』は当ツール実測では≈0.62に出る（分母が広いため）。→ 学術ノルムからは**方向と相対的な広がりのみ**を採り、**中心は当ツールの実測スケールに合わせた値**（faceAspect 0.63 / eyeSize 0.20 / eyeLevel 0.36）に設定し、**低重み**で補助に留める。
  - これらは「1サンプルからの暫定中心」を含むため過信しない。**実データが集まれば最優先で再較正**する（`calib.js` の該当centerのみ差し替え）。
- 結論：**軸の判定は(A)の出典確実な指標が主導**し、(B)は微調整。これで機器スケールのズレが結果を支配しない設計にする。

## おもざし軸（子供 ↔ 大人）

| 指標 | 中心（平均） | 子供寄り | 大人寄り | 根拠・出典 |
|---|---|---|---|---|
| **下顔面比** (menton−subnasale)/(menton−nasion) | **0.50** | < 0.47（下顔面短い） | > 0.53（下顔面長い） | 新古典canonの「顔の三分割」で鼻部(nasion–subnasale)と下顔面(subnasale–menton)はほぼ等分＝0.5。baby schemaで乳幼児は下顔面が相対的に短い（＝低い比）。**主軸・最信頼** |
| **顔の縦横比** (menton−nasion)/bizygomatic | **0.87** | < 0.84（幅広・短い＝euryprosopic） | > 0.90（面長＝leptoprosopic） | Prosopic/顔面指数の分類：euryprosopic 80–85 / mesoprosopic(平均) 85–90 / leptoprosopic 90–95。乳幼児は「短く幅広い顔」。※y10非依存のnasion基準。中信頼 |
| **目の縦位置**（アイレベルが顔の上下どこか） | 顔の上下やや上 | 目が中央〜下（額広い） | 目が上 | baby schema：乳幼児は額が大きく眉が中心線＝目が相対的に下。成長で額が縮み顎が伸びる。中信頼 |
| **目の相対サイズ** 目幅/顔幅 | **≈0.22**（片目） | 大（目が大きい） | 小 | baby schema：子供は目が相対的に大きい。瞼裂幅≈28–31mm÷顔幅≈130mm。中〜小信頼（開眼/メイク交絡） |

## 正規化・採点方針（07反映）
- 各指標は中心を0、片側の帯幅で ±1 にスケール（`v = clamp((x − center)/halfBand)`）。min-max混用しない。
- おもざしスコア `S_age` = Σ(w·v)/Σw（下顔面比＝大重み、顔縦横比・目縦位置＝中、目サイズ＝小）。
- かたちスコア `S_shape` = Σ(w·v)/Σw（canthal tilt＝主、目の丸み＝中、顎幅比＝小）。
- 3帯（|S|<0.33=中間 / それ以上で子供|大人・曲線|直線）→ 8マス割付（中央は最近傍＋ミックス）。
- 確信度：|S|が大・品質良で「目安」、小・品質NG・非対角セルは「参考」。**高は出さない**。

  - Facial Proportionality（Qoves, evidence-based）: https://www.qoves.com/insights/facial-proportionality
  - Neoclassical canons の妥当性検証（Farkasが多くの個人で不成立と報告）: https://head-face-med.biomedcentral.com/articles/10.1186/s13005-015-0064-y

- baby schema（子供の顔＝短く幅広・大きい目・額大）: Lorenz baby schema レビュー https://pmc.ncbi.nlm.nih.gov/articles/PMC11285920/ ／ 顔の発達プロポーション（一般教材）
