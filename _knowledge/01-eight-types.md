# 01 8タイプ定義（独自名・軸位置・顔特徴・印象）

2軸マップ（横＝かたち軸 曲線↔直線／縦＝おもざし軸 子供↔大人）の四隅＋各辺中点に配置した独自グリッド。名称・特徴・印象文はすべてMemoroオリジナルの書き起こし（既存商標体系の固有名称・記述は不使用）。

## マップ配置（イメージ）
```
              曲線的 ←――――――― 中間 ―――――――→ 直線的
子供っぽい   ふんわり甘めタイプ         さわやか可憐タイプ          軽やかナチュラルタイプ
   ↑
  中間       やわらか上品タイプ        （中央）           すっきり洗練タイプ
   ↓
大人っぽい   華やか大人タイプ         たおやか気品タイプ            凛とシャープタイプ
```

## 判定の主眼（各タイプがどの測定で立つか）
- **おもざし軸を決める**：顔の縦横比（丸短→子供／面長→大人）、下顔面比、目の縦位置、目の相対サイズ、パーツの相対サイズ・上下分布。
- **かたち軸を決める**：フェイスライン曲率・顎先の角度、目の縦横比（丸目→曲線／切れ長→直線）、目尻角度、複数の輪郭・パーツ形状の合成（ただし輪郭系は低信頼＝07）。
- **四隅タイプ（ふんわり甘めタイプ・軽やかナチュラルタイプ・華やか大人タイプ・凛とシャープタイプ）**は両軸とも極に振れ確信度が出やすい。**辺中点タイプ（さわやか可憐タイプ・やわらか上品タイプ・すっきり洗練タイプ・たおやか気品タイプ）**は片軸が中間＝ミックス表示・確信度控えめ。
- 🔴 非対角（子供×直線＝軽やかナチュラルタイプ／大人×曲線＝華やか大人タイプ）は2軸相関のため母集団が薄い可能性 → 該当時は確信度を特に控えめに（07）。
